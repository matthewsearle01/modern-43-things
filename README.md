A modern reimagining of the original 43 Things social goal tracking platform.

Built as a frontend-focused project using:

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase (backend as a service)

# Development

## Install dependencies:
```
npm install
```

## Run locally:

```
npm run dev
```

## Build:
```
npm run build
```

## Lint:
```
npm run lint
```

## Format:
```
npm run format
```
